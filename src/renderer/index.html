¿Cómo obtener la API Key?

1

Visita console.groq.com

2

Crea una cuenta gratuita con Google o Github.

3

Ve a la sección API Keys del menú.

4

Haz clic en "Create API Key".

5

Copia el código y pégalo en el campo de arriba.

Consejo

La API de Groq es completamente gratuita para uso personal. No necesitas tarjeta de crédito.
